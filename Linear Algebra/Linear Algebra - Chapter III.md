# Basis

>**Definition:**
>an *independent* & *generation set* of subspace $V$.
##### Properties
0. the set of <u>pivot columns</u> are basis.
1. Basis is the <mark style="background: #FF5582A6;">smallest generation</mark> set of a subspace.
2. Basis is the <mark style="background: #FF5582A6;">largest independent</mark> vec. set of a subspace.
3. the <u>number</u> of vector in basis of subspace is <u>fixed</u>.
	- the number is called ***dimension***.

⇒  independent vec. set → **basis** → generation set
##### Check if it's a basis
1. if: *the size of vec. set* equals to $dim$
2. *independent* or *generation set*

>##### Dimension Theorem:
>$Dim\, of\, Range + Dim\, of\, Null = Dim\, of\, Domain$

# Coordinate System
### Definition
1. every vector has representation ⇔ the span of $B$ is $R_n$
2. unique representation ⇔ $B$ is independent

⇒  $B$ is a ***basis*** of $R_n$

The same vector could be different in the different coordinate system.
### Change Coordinate
$v = B[v]_B$
