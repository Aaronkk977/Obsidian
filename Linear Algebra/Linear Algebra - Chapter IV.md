# Determinant
#### Coefficient Expansion

#### Basic Properties
1. $det\,(I)=1$
2. switch two rows → sign change
3. *linear* for each row                       
##### More Properties
1. **Diagonal/ Upper/Lower** Triangular Matrix's $det$ = $d_1d_2...d_n$ 
2. <mark style="background: #BBFABBA6;">Important</mark>：$det A\neq0$ ⇔ $A$ is **invertible**
3. $det(AB) = det(A)det(B)$
4. $det(A^T) = det(A)$
